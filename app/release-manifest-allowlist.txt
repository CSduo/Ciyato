# What the RELEASE build is allowed to ship.
#
# Checked by the `verifyReleaseManifest` Gradle task against the merged release
# manifest, not against app/src/main/AndroidManifest.xml. Those are different
# documents: AndroidX, WorkManager and the profile installer all contribute
# permissions and components that the source manifest never mentions, and a
# dependency upgrade can add one silently. Play policy and runtime behaviour are
# judged on what ships (F-184).
#
# A difference in either direction fails the build. An addition is a new
# capability nobody reviewed; a removal is a feature that has gone quiet - and
# this repository has now produced three of those, each one silent:
# PACKAGE_USAGE_STATS undeclared while six screens queried usage stats, two
# Quick Settings tiles undeclared, and a notification listener declared
# android:exported="false" so the system could never bind it.
#
# To change this file: state why in the commit message, and add a row to
# DATA_INVENTORY.md if it is a permission.
